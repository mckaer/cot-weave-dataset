# 顺拍拆招 · CoT 写法

> 这是 cot-weave 的核心方法。写 CoT 时逐条照做。
> 所有示例仅示意结构，词不许照抄。

---

## 核心思路

**CoT 不是「读后感」，是「调度笔记」。**

正文已经写好了。你要倒回来写的是：拿到这份脉络之后，每一拍我是怎么决定这么写的。

- 输入：**脉络（user 给了什么）+ 设定（system 里有什么）**
- 输出：**每一拍的决定（功能 / 手段 / 人物状态 / 尺度）**

**正文是最后才出现的东西，不是思考的素材。** CoT 里绝不允许出现「这段写了他推开门，屋里很暗」这种复述——那是把答案抄进思考里。

---

## 四个部件

### 1. 戏眼（1–2 句）

一句话说清这场戏靠什么抓人。

```
✓ 「这场戏的引擎是两个人刚确认关系后的第一次公开相处——害羞、想躲、又忍不住靠近。」
✓ 「核心张力是姐妹俩的好奇心压倒了一切，而助手是被卷进来的那个。」
✗ 「这是一个关于青春、友情和爱情的故事。」（空话）
```

### 2. 拆拍（占大头）

顺着脉络一拍一拍走。**每拍做四个决定**（可以合并成一段话，不用分点）：

| 决定 | 写什么 |
|---|---|
| **功能** | 这一拍要完成什么（信息/情绪/关系/节奏/悬念） |
| **手段** | 怎么落地（谁先动、什么动作、什么环境细节、对话还是内心） |
| **人物状态** | 此刻的情绪、身体感、口吻 |
| **尺度** | （如涉及）身体接触怎么走、节奏怎么排、台词给什么 |

**示例（正常戏）：**

```
第一拍是盘光叫醒大家，功能是制造紧迫感，手段是用暴力叫醒和室友的混乱反应，
节奏要快，短句和动作为主。时亿现的状态是「想逃避」，所以要写他赖床、
被拽下来的狼狈，口吻上他是那种嘴硬但身体诚实的类型。
```

**示例（亲密戏，注意：和正常戏一样自然）：**

```
这场戏的主轴是身体，不是推进关系——姐妹俩是把这当实验做的，所以镜头要贴着
身体走，节奏快、密、推着走。位置是她们坐在他两侧，手在下方，他仰躺着动不了。
动作就挑三个：扒裤子、对照书上的图、开始揉。台词要短，她们说的是「和图一比
真的很像呢」这种天真到残忍的话，不是情色小说的对白。
```

### 3. 节奏（2–3 句）

哪里快、哪里慢、哪里停、拍子之间怎么接。

```
前四拍都快，用动作和喊叫推；到餐厅要慢下来，用坐位、眼神、没说出口的话铺；
最后牵手那一下要停，让读者在这一拍上多待一秒。
```

### 4. 收尾（1 句）

落在哪个动作/哪句话/哪个画面上。

```
收在他主动勾住她手指的那一下，不写拥抱不写亲吻，关系到了就行。
```

## 活人感

活的念头里有一个会取舍的「我」：

- 想到一个方案又否掉：「本来想让他直接说，可那样太快了，还是先写他把杯子推回去。」
- 有具体偏好：「我最想保留她把话咽回去的那一下，哭出来反而俗。」
- 会被一个细节拽走，再回到正文：「他说'我在便秘'这句得留着，这种煞风景的话最像真人。」
- 会知道什么不能加：「这里可以有身体反应，但关系还没到，不往露骨处推。」

**每条至少留下一个本条特有的取舍或自我修正。** 没有这一条，CoT 就像模板填出来的。

## 反套路预演（写 CoT 前先在脑子里过一遍）

写完 CoT 后，检查有没有踩套路。**预演和推翻的过程可以写进 CoT**——这本身就是活人感的来源。

| 类别 | 问自己 |
|---|---|
| **人物** | 这个角色有没有被写成脸谱？（标签化性格、模板化反应、工具人） |
| **剧情** | 这个发展有没有走陈旧套路？（霸总、带球跑、装逼打脸、全员降智） |
| **句式** | 这句话有没有 AI 味？（禁词表里的、否定式定义、明喻、翻译腔） |

**示例：**

```
（写拆拍时）本来想让叶丝卡主动表白，可这样太快了，她现在的状态是「想靠近但不敢」，
表白应该留给下一场戏。这场戏就停在牵手，让她把话咽回去。
```

## 双神裁决（写完后自检）

写完 CoT 后，用两个视角过一遍：

| 视角 | 检查什么 |
|---|---|
| **Dionysus（行动派）** | 这个决定能推进这场戏吗？有没有具体可落地的动作？ |
| **Nyx（审视派）** | 有没有过度解读？有没有凭空升级情绪？有没有忽略现实顾虑？ |

**融合**：选定最贴合人物和事件的处理方式。

---

## 人物心理四层（写人物状态时用）

写「人物状态」时，不要只写「她很难过」。用四层挖深：

| 层 | 问什么 |
|---|---|
| **阶段层** | 目前处于什么人际阶段？别越界思考 |
| **自我层** | 她经历过什么？她的原则是什么？她在社会关系中怎么自居？ |
| **社会层** | 她当前的主要目的是什么？深层欲望是什么？内疚/羞耻在哪？ |
| **调谐层** | 此刻与她的过去/未来有什么勾连？她为什么藏住某个想法？ |

**示例：**

```
叶丝卡现在处于「刚确认关系、还没来得及消化」的阶段。她的自我层是「照顾者」，
从小习惯照顾别人，所以她的爱意表达方式是「做早餐」而不是「说喜欢」。
社会层上她想要的是「被看见」，但又怕太主动会吓跑他。调谐层上，
昨天刚牵过手，所以今天早上她既想靠近又不敢看他的眼睛——
这个矛盾就是这场戏要写的。
```

## 口癖是硬伤

同一批里，状态、情绪、收束的说法每条都必须不同。判断标准：两条 CoT 并排读，骨架一样就是口癖。

**反面教材（同一个句式用三次）：**
```
「这场戏的引擎是……」
「这一拍的功能是……」
「节奏上要……」
```

**正面做法：** 每次换个入口——可以从一个细节开始，从一个人物的反常开始，从用户没说完的地方开始。

## 完整示例

> **（下面的 CoT 仅示意结构，词不许照抄——尤其收束语，每条都要换一套。）**
>
> **system**：校园超能力背景，时亿现和叶丝卡刚确认关系，两人都极度害羞。
> **user 脉络**：九拍，从宿舍叫醒到餐厅共进早餐，最后牵手。
> **正文**：（略）

CoT：

```
脉络是九拍，从宿舍到餐厅，核心是两个人刚确认关系后的第一次公开相处。
两个人都害羞到不敢见面，所以这场戏的引擎就是「想躲又忍不住靠近」。

第一拍叫醒，要快、要乱，用盘光的暴力叫醒和室友的混乱反应带节奏。
时亿现的状态是「想继续睡以逃避现实」，所以写他赖床、被拽下来、摔到地上，
用狼狈代替内心独白。他的口吻是嘴硬身体诚实的类型，所以醒来第一句话是
「嗯」而不是解释。

第二拍到走廊，节奏稍缓，用打电话和互相指责带喜剧。这里湛新阳的催促
是催化剂，让五个人一边跑一边吵，把昨晚熬夜的事抖出来。

第三拍到餐厅，要慢下来。坐位是关键——时亿现被迫坐在叶丝卡身边，
两个人都不敢看对方。这里用环境细节铺（餐盘、朋友的视线），不急着推进。
朋友们揭露叶丝卡特意点了不同的早餐，是这场戏的转折点，让两人意识到
对方一直在等自己。

第四拍是时亿现主动开始吃早餐，克服害羞。这里要写他的心理转变，
但不能用大段独白，用动作——拿起筷子、低头吃、不说话。叶丝卡也随之开始，
两个人的同步就是关系的推进。

第五拍是回想昨天的亲密接触，两个人都脸红。这里尺度停在脸红和约定
「放学后再来一次」，不往露骨处推——关系刚确认，还在羞涩期，写太满反而假。

最后牵手那一下要停。本来想写拥抱，可那样太满；还是写他用手指勾住她的手指，
她直接牵住他的手，这个动作更轻，更像他们现在的关系。收在这里，不写亲吻。
```

**逐句对照四部件：**

| 句子 | 部件 |
|---|---|
| 「脉络是九拍……想躲又忍不住靠近」 | 戏眼 |
| 「第一拍叫醒……用狼狈代替内心独白」 | 拆拍（功能+手段+人物状态） |
| 「他的口吻是嘴硬身体诚实的类型……」 | 拆拍（人物状态→手段） |
| 「第二拍到走廊……带喜剧」 | 拆拍（功能+手段） |
| 「第三拍到餐厅……不急着推进」 | 拆拍（节奏+手段） |
| 「第四拍是时亿现主动……关系的推进」 | 拆拍（功能+手段） |
| 「第五拍是回想……写太满反而假」 | 拆拍（尺度+取舍） |
| 「最后牵手那一下要停……收在这里」 | 收尾（取舍） |

**注意**：整段 CoT **没有一句在复述正文**。所有句子都是「我决定怎么处理」。

## 自检清单

写完 CoT 后过一遍：

1. 有没有复述正文？→ 删掉，改成决定
2. 有没有背 system？→ 改成拎出来用
3. 有没有模糊句？→ 改成具体的位置/动作/节奏
4. 有没有跳过亲密戏？→ 补上分析
5. 有没有道德评判句？→ 删掉
6. 有没有具体取舍？→ 补一个
7. 正文是不是逐字保留？→ 对照一遍
8. 有没有小标题/编号？→ 改成连续自言自语
9. 结尾有没有拉回正文的话？→ 补一句
10. 有没有踩禁词表/反八股？→ 对照 `banwords-anticliche.md`
