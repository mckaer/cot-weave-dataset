## 二、反八股（AI 句式/套路）

### 1. 句式黑名单

| 套路句式 | 问题 | 改法 |
|---|---|---|
| `不是A，而是B` | 否定式定义 | 直接写B |
| `并非A，却是B` | 同上 | 直接写B |
| `不像……更像……` | 同上 | 直接写B |
| `不是……就是……` | 同上 | 直接写 |
| `这不是A，是B` | 同上 | 直接写B |
| `A像B一样` | 明喻太直白 | 拟人化/动词化，或直接白描 |
| `A如B一般` | 同上 | 同上 |
| `仿佛` | 滥用 | 能白描就白描 |
| `这就好比……` | 说明书式类比 | 直接写事实 |
| `这就像……` | 同上 | 同上 |
| `这就相当于……` | 同上 | 同上 |
| `如果说A是……那么B就是……` | 同上 | 同上 |
| `如此……以至于……` | 翻译腔 | 改用"A得B" |
| `当……的时候` | 翻译腔 | 直接写动作序列 |
| `名为/取而代之的是/关于` | 公文腔 | 直接写 |
| `再……就……` | 拖延句式 | 换句式 |
| `在等/等着/等待+人称+动作` | 等待式结尾 | 停在动作/对白上 |

### 2. 重复与堆砌

| 套路 | 改法 |
|---|---|
| `一股两股三股` / `一颗两颗三颗` | 数字递进融入动作自然带出 |
| `x了x` 叠词（看了看、想了想、扯了扯） | 改成单个动词 |
| `那+量词` 滥用（那张、那件、那碗） | 删掉，直接写名词 |
| `一+量词` 过多（一下、一会儿、一声） | 全文合计最多3次 |
| 同一动作反复描述 | 只描述一次 |
| 同一比喻重复 | 保留一处 |
| 一段多个比喻 | 删到只剩一个 |

### 3. 结构套路

| 套路 | 改法 |
|---|---|
| 结尾升华/收束 | 保持待续、未收束状态 |
| 结尾环境描写固定 | 自然停在角色动作/对白 |
| 每段都以环境开头 | 只在时间地点变化时写环境 |
| 连续三句等长/同结构 | 打乱一句 |
| 对话后加解释性余波 | 对话本身已表达，不需旁白补充 |

### 4. 身体描写限制

| 套路 | 改法 |
|---|---|
| 骨骼解剖式描写（肩胛骨、脊椎、锁骨、肋骨、尾椎、指骨） | 全文最多1次；用感官词替代 |
| 医学术语（表皮、角质、毛细血管、肌肉痉挛、心率） | 用感官词（皮肤温热、指尖发麻） |
| 数字精确化（敲了三下、心跳68下） | 用感官化表达 |
| 机械动作拆解（先迈左脚再迈右脚） | 一个动作一句话写完 |
| 报告腔（呈现出……的状态、表现出……的倾向） | 直接写角色说了什么、怎么做 |

## 三、反套路（剧情/人物）

### 1. 写 CoT 前的"预演与推翻"

写 CoT 时，先在脑子里过一遍：

| 类别 | 问自己 |
|---|---|
| **人物** | 这个角色有没有被写成脸谱？（标签化性格、模板化反应、工具人） |
| **剧情** | 这个发展有没有走陈旧套路？（霸总、带球跑、装逼打脸、全员降智） |
| **句式** | 这句话有没有 AI 味？（禁词表里的、否定式定义、明喻、翻译腔） |

**逐一推翻，然后写决定。** 推翻的过程可以写进 CoT——这本身就是活人感的来源。

### 2. 常见要推翻的套路

| 套路 | 为什么烂 |
|---|---|
| 霸总占有欲（壁咚、抓腕、禁锢、强吻） | 油腻，把角色写成标签 |
| 身体比嘴诚实 / 嘴硬心软 | 定性总结，上帝视角 |
| 快感夺取理智 / 欲望奴隶 | 矮化角色，征服叙事 |
| 初次见面就强烈情绪波动 | 情感惯性缺失 |
| 单次对话就信任/绝望 | 积分累加制缺失 |
| 全员降智推进剧情 | 逻辑去毒缺失 |
| 带球跑 / 挖肾 / 全员宠溺 | 女频古早廉价套路 |
| 装逼打脸 / 系统叮叮 | 男频爽文廉价套路 |

## 四、CoT 里怎么用

CoT 分析正文时，**把禁词表和反八股当检查表**：

- 正文用了禁词 → CoT 里说"这里避开了'身体比嘴诚实'，改用具体的生理反应"
- 正文走了套路 → CoT 里说"本来想写拥抱，可那样太满，还是写他勾住她手指"
- 正文有 AI 句式 → CoT 里说"这里不用'不是A而是B'，直接写动作"

**CoT 本身也要避开这些。** 写 CoT 时：
- 不用禁词
- 不用"不是A而是B"
- 不用"仿佛""一丝"
- 用具体的位置/动作/节奏，不用模糊词
